## [Medium] Cookie?
因flask是個輕量化的框架，輕到連SESSION都丟到USER端以"cookie"的形式儲存，但是與cookie還是稍有不同，cookie若沒有額外設計就是以明碼儲存，session則是以"加密"的形式儲存
雖說有加密，但不多，flask僅用一個變數"secret_key"來儲存密鑰，且對密鑰幾乎毫無限制，因此非常容易破解，可以參考
https://github.com/noraj/flask-session-cookie-manager
https://www.kirsle.net/wizards/flask-session.cgi
只要找到名為session的cookie，再將值輸入工具破解，就可以找到flag
